Iris Flower Dataset¶

This notebook has been made and produced in jupyter notebook on august 10th 2025, and the last for this dataset was 7 years ago¶

The notebook is being made by José de Jesús Hernández Vázquez¶

Dataset can be found in: https://www.kaggle.com/datasets/arshid/iris-flower-dataset¶

Context according to kaggle "The Iris flower data set is a multivariate data set introduced by the British statistician and biologist Ronald Fisher in his 1936 paper The use of multiple measurements in taxonomic problems. It is sometimes called Anderson's Iris data set because Edgar Anderson collected the data to quantify the morphologic variation of Iris flowers of three related species. The data set consists of 50 samples from each of three species of Iris (Iris Setosa, Iris virginica, and Iris versicolor). Four features were measured from each sample: the length and the width of the sepals and petals, in centimeters."¶

3.- Visualization¶

Now that we see the statistic parts of petals and sepals (width and length), we can proceed to make it more visually explainative using a Histogram and a Pairplot¶

With an histogram we can actually visualize the distribution of a feature and with the pairplot we can actually see the numeric relation and if there's (if any) visual serpability between classes¶

Histogram¶

In [8]:
fig, axs = plt.subplots(2,2, figsize = (10,6))

species = data["species"].unique()
colors = ["#0046FF", "#FF9B00", "#08CB00"]

# Variables and titles
features = ["petal_length", "petal_width", "sepal_length", "sepal_width"]
titles = ["Petal Length", "Petal Width", "Sepal Length", "Sepal Width"]


for ax, feature, title in zip(axs.flat, features, titles):
    for sp, color in zip(species, colors):
        subset = data[data["species"] == sp]
        ax.hist(subset[feature], bins = 15, alpha = 0.6, label=sp, color=color)
    ax.set_title(f"{title} Histogram")
    ax.set_xlabel("cm")
    ax.set_ylabel("Frequency")
    ax.legend()

plt.tight_layout()
plt.show()
When it comes to petal length we can totally see how iris setosa shows petals with a size minor to 2cm, which allows us to easily discrimante it, while versicolor and virginica are more difficult to tell apart since they're both in the region between 4 and 5 cm. We can also do this for petal width since setosa is at 0.5 or lower, while versicolor and virginica are somewhere between the 1.5 region. When it comes to sepal length and width we can see it's where the three species are having almost the same values and overlapping each other, meaning that this isn't actually a good feature to use for discrimination.¶

5.- Model Comparison¶

I've decided to use LinearSVC thanks to a guide from scikit-learn (https://scikit-learn.org/1.3/tutorial/machine_learning_map/) however I want to test LinearSVC against some more popular models bieng this Random Forest and KNN¶
In [15]:
X = data[["petal_length", "petal_width", "sepal_length", "sepal_width"]]
y = data["species"]

le = LabelEncoder()
y_encoded = le.fit_transform(y)

X_train, X_test, y_train, y_test = train_test_split(
    X, y_encoded, test_size=0.2, random_state=42, stratify=y_encoded
)

scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)
In [16]:
models = [
    ("LinearSVC", LinearSVC(max_iter=10000, random_state=42)),
    ("KNN", KNeighborsClassifier()),
    ("RandomForest", RandomForestClassifier(random_state=42))
    ]
In [17]:
# Train, predict and evaluate each model
results = []


for name , model in models:
    if name in ["LinearSVC", "KNN"]:
        model.fit(X_train_scaled, y_train)
        preds = model.predict(X_test_scaled)
    else:
        model.fit(X_train, y_train)
        preds = model.predict(X_test)
    
    # Metrics

    acc = accuracy_score(y_test, preds)
    results.append((name, acc))
    
    print(f"\n{name}")
    print(f"Accuracy: {acc:.3f}")
    print(f"Confussion Matrix:\n", confusion_matrix(y_test, preds))
    print(f"Classification Report:\n", classification_report(y_test, preds, target_names=le.classes_, zero_division=0))
